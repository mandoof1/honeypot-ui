# Code of conduct

Everyone is welcome to participate in HoneySentinel. Treat people with respect
regardless of their background, identity, or level of experience. Give feedback
about the work, explain disagreements in good faith, and respect people's privacy.

Harassment, threats, discriminatory language, unwanted sexual attention, and
sharing someone's private information without permission are unacceptable.
These standards apply to issues, pull requests, reviews, and other project spaces.

## Reporting and moderation

Use GitHub's **Report content** menu to flag abusive content. If GitHub offers
**Report to repository admins**, you can send it to the maintainers. You can
also [report it directly to GitHub Support](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Include links to the relevant content and a brief description. Keep personal
information out of public comments. Maintainers may remove content, restrict
participation, or block accounts when needed to protect the community.
